Live Demo • KFZ Werkstatt

Erst Diagnose, dann Daten.
So zahlt man gern dafür.

Diese Demo ist kategorie-spezifisch. Wenn jemand nur sagt „Ich habe ein Problem“, fragt der Agent sinnvoll nach (Symptome → Dringlichkeit → Kontext → nächster Schritt). Name/Telefon kommen erst später.

Problem zuerstDer Agent fragt erst nach Symptomen/Grund – nicht nach Namen.
Triage & SicherheitNotfall-Hinweise + “Fahrbereit?” / “Wasser abgestellt?”
Saubere ÜbergabeZusammenfassung + Copy + E-Mail ans Team.
Du kannst in der Konfiguration die Kategorie wechseln (KFZ / Sanitär / Zahnarzt / Allgemein).
